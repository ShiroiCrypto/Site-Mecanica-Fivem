# 🚗 Oceania Customs - Site da Mecânica | FiveM

![Logo Oceania Customs](https://github.com/ShiroiCrypto/Site-Mecanica-Fivem/raw/main/assets/logo.png)

Bem-vindo ao repositório oficial da **Oceania Customs**, a melhor mecânica da cidade Oceania (FiveM)!  
Este site foi desenvolvido como uma calculadora para uso dos mecânicos, facilitando a cobrança e o atendimento dos clientes de forma rápida, organizada e responsiva.

---

## 📦 Tecnologias Utilizadas

- HTML5
- CSS3 (Responsivo)
- JavaScript Puro
- Hospedagem: [Square Cloud](https://squarecloud.app/)

---

## 💻 Funcionalidades

- ✅ Calculadora de valores com base no tipo de veículo e serviços selecionados  
- ✅ Aplicação automática de descontos (parcerias de 10%, 15% e 20%)  
- ✅ Design leve, moderno e compatível com dispositivos móveis  
- ✅ Interface pensada para uso prático no dia a dia dos mecânicos
